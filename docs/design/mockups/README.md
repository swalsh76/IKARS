# Terminal mock-ups (M1.3)

The source of the clickable mock-ups the owner reviewed in M1.3. Each `.dc.html` file is one screen
of a Design canvas; `canvas.json` lays them out. All data in them is made up (`KXDEMO-…`,
`[BALANCE]`, `[LEVEL]`).

| File | Screen |
|---|---|
| `Main.dc.html` | Overview, the main screen (with a light/dark toggle) |
| `Market.dc.html` | Drill-down to a market, with the cross-reference panel |
| `Recommendation.dc.html` | Drill-down to a recommendation |
| `Health.dc.html` | Health |
| `Alerts.dc.html` | Alerts by priority, and hotkeys |
| `Layout.dc.html` | A two-monitor layout sketch |

**Status:** approved for now by the owner (2026-10-27), and revisable before M1.8 builds the screens in WPF.
M1.8 follows these screens; any change to them is drawn here first.
